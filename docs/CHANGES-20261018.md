  - **阶段一（短写锁）**：磁盘预检、执行内存变异、提取只读快照副本（CoW 浅拷贝字典/切片引用，纳秒~微秒级），立即释放读写锁；

### 2. CoW 克隆粒度细化（项 29 / P1-1）
- **杜绝 O(N²) 重复克隆**：

### 3. `onWarning` 移出写锁（项 30 / P1-33）
- **排队与锁外统一派发**：
  - 5 门语言统一引入 `pendingWarnings` 内部队列；
  - 持有写锁期间（如自动压实失败、目录 fsync 不支持等）只入队告警信息；
  - 在完全释放读写锁之后统一向用户配置的 `onWarning` 回调派发，彻底消除因在告警回调中重入读库导致的死锁隐患。

### 4. 提交失败后的脏标记保留与内存原子回滚（项 31 / P0-7、P1-6）
- **内存原子回滚机制**：
  - 写操作前记录受影响命名空间的原始快照指针；
  - 一旦序列化、落盘 `fsync` 或轮转发生 IO 异常，立即原子回滚内存到写操作前状态；
